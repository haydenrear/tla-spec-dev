## 1. The one sentence

**The loop this whole programme aims at — hand-found regression → card iteration
→ architectural delta → re-score — cannot be run by anyone who did not build it,
and has never been run end to end even by us.**

This epic is small and it is a gate. Nothing about transfer, static analysis or
spectral signal can be measured until it works.

---

## 2. The three things that block it

**The change rule is unrunnable and fails silently.**
`SUPPORTED_VERSIONS = (1,2,3,4)` is a literal in our source, so an adopter
bumping to 5 must edit our code — and a v5 card is **stamped `version 4` with
`check` reporting 0 problems.** Worse, **the seal does not seal what a judge
reads**: rewriting a caveat deletes it from the served bytes while
`anchors_digest` stays byte-identical.

**A price cannot mean anything yet.** The normal shape of a removal here —
every killing node inside a deleted file — **always** returns
`ENTAILED-SURVIVES`, because that verdict follows from `git show` alone. The
previous epic's headline "first PRICED removal" was **withdrawn**: its own
zero-gap control returned the same verdict, and that row was **missing from the
four-row output the report printed as three.**

**The loop's input is being produced and dropped.** Two blind judges, in two
different tickets, independently found that `reference_ports`'s real adapter can
stop touching the filesystem and survive both wirings. **Filed zero times**,
under twenty-two `D3 = 4` cards.

---

## 3. The metric, and it is not repository lines

**`serve | wc -c`.** The served rubric — what a judge is actually handed — is the
only surface this project has ever shrunk: **8,396 → 6,409 bytes, −23.7%**, and
**25 → 9 anchor rungs**. It was byte-identical at every version-3 commit across
two whole epics.

Repository lines are net-additive **by construction**: the change rule keeps old
anchors and `R-H4` seals the record, so a card removal cannot delete prose or
code. Three epics called themselves simplifications for nothing.

> **The served surface is 6,409 bytes and 9 rungs. That is the room every
> re-add has to work in. Do not grow it.**

An **anchor** is permanent — the change rule forbids deleting the old one. A
**prompt** costs nothing against the sealed surfaces. Prefer prompts.

## 4. What comes after, and only after

`RM-05` §11 is explicit about order: **then, and only then, prompt architecture
back in.** Static analysis and spectral signal come after something can be

## 5. Doctrine that carries forward unchanged

- **No new gates.** Six epics, zero bugs caught by a static check.
- **The typology, corrected by measurement**: the discriminator is **open vs
  closed population**, not record-vs-gate. `total` gated. D2's anchor 4 gated —
  it capped D2 eight times. Both were removed anyway. A thing survives when what
  it ranges over is fixed and nameable.
- **`MF-020`**: never add an axis fitted to a known answer. The clearest
  invitation this project ever produced was refused twice.
- **R1**: an instrument ships with a demonstrated *failing* input on a real
  subject.
- **`denominator_rule`**, including suite counts.
- **Seal predictions BEFORE measuring, and say when.** Last evaluation declared
  an ALARM against itself for sealing after.
- **File findings; fix nothing during a measurement.**
- **Ask every blind agent what it REJECTED.**

## 6. Operational rules this project has paid for

- **`wt new` branches from the LOCAL ref.** It has put tickets 4, 14 and 21
  commits behind. **Verify your branch point against the SHA in your work order.**
- **Do NOT report `git archive` figures as tree properties** — those tests read
  git history and an archive has no `.git`.
- **Do NOT hand-roll a wait loop for a run you started.**
- **Never kill a process by name alone**, and check whether a process is yours
  before touching it. Three agents have correctly left a stranger's run alone.

**Two reds are inherited deliberately.** `RM-06-DF-01` (the same-tag control
cannot tell treatment from architecture) and
`test_nothing_in_the_repository_invokes_the_pricer`, which `NEXT-EPIC.md` trips
by *mentioning* `price_removal`. If you repair the second, **exempt narrative
documents as a class** — do not allow-list one file.
