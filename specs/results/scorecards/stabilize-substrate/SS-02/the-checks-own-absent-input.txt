The self-referential trap: absent-input is itself an instrument that can be handed
an absent input. If any run below exited 0 it would be the 49th instance of the
class, shipped inside the fix for the class. All six exit 2 and all six SAY WHICH
STATE THEY HIT, which is the property this check demands of everything else.

NOTE THE COLLISION, disclosed rather than hidden: argparse also exits 2 for a
usage error, so the CODE alone does not separate 'UNDECIDED' from 'you typed the
command wrong'. The first line of output always does. Filed as SS-02-DF-02.
